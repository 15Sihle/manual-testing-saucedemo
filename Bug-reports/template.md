# Bug Report

## Bug ID
BR-001

## Title
Cart item count does not update immediately after removing a product

## Environment
- Browser: Google Chrome
- Operating System: Linux
- Application URL: https://www.saucedemo.com

## Preconditions
- User is logged in
- User is on the Products page

## Steps to Reproduce
1. Add a product to the cart
2. Verify cart icon shows item count as 1
3. Click “Remove” on the same product

## Expected Result
Cart icon item count should update immediately and show zero items

## Actual Result
Cart icon item count remains visible for a short time after removing the product
