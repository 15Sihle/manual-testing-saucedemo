# Test Plan – SauceDemo Web Application

## 1. Introduction
This test plan describes the testing strategy, scope, and approach for manually testing the SauceDemo web application.

## 2. Objective
The objective of this testing is to ensure that the core functionalities of the SauceDemo application work as expected and provide a good user experience.

## 3. Application Under Test
- Name: SauceDemo
- URL: https://www.saucedemo.com

## 4. Scope

### 4.1 In Scope
- Login functionality
- Product listing
- Add to cart
- Remove from cart
- Checkout process
- Logout functionality

### 4.2 Out of Scope
- Performance testing
- Security testing
- Load and stress testing
- Database testing

## 5. Test Types
- Functional Testing
- Smoke Testing
- Regression Testing
- Negative Testing

## 6. Test Environment
- Browser: Google Chrome
- Operating System: Windows / Linux
- Test Type: Manual Testing

## 7. Test Approach
Manual testing will be performed by executing predefined test cases and comparing the actual results with the expected results.

## 8. Entry Criteria
- Application is accessible
- Test environment is available
- Test cases are prepared

## 9. Exit Criteria
- All planned test cases executed
- Critical defects identified and reported
- Test summary report completed

## 10. Deliverables
- Test Plan
- Test Cases
- Bug Reports
- Test Summary Report

## 11. Roles & Responsibilities
- QA Engineer: Test case design, execution, defect reporting

## 12. Risks & Mitigation
| Risk | Mitigation |
|-----|-----------|
| Application unavailable | Test when site is online |
| Limited test data | Use provided demo credentials |

## 13. Approval
This test plan is approved for execution.
